# Goal Tracker

A small personal project for tracking goals, journal entries, and coaching topics.

**Stack:** Bun monorepo · Hono API on Cloudflare Workers · D1 (SQLite) · React 19 SPA · Tailwind CSS v4 · React Router v7

## Commands

```bash
bun install
bun run dev          # API + web concurrently
bun run dev:api      # API only (:8787)
bun run dev:web      # Web only (:5173)
bun run setup:db     # Initialize local D1 database
```
